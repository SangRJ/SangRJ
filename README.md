### 👨‍💻 About Me

Senior Software Engineer with **3+ years of professional experience** and a completed **Bachelor of Science in Computer Science**. 

I specialize in building high-throughput, fault-tolerant backend architectures with **Elixir, Phoenix LiveView, and PostgreSQL**, as well as full-stack enterprise applications and hardware integrations. My work powers production systems across **digital banking, national e-tolling, payment gateways, biometric gym administration, arcade operations**, and **offline healthcare AI diagnostics**.

- 🔭 **Currently Building:** Scalable enterprise backends, payment workflows, and real-time supervisory portals.
- 💼 **Primary Focus:** Distributed systems, relational data integrity, and low-latency API architectures.
- 🎓 **Education:** BSc in Computer Science (ZCAS University) & Diploma in Computer Studies (Evelyn Hone College).
- 🧠 **Research:** Explored deep learning & explainability for offline brain MRI tumour classification using EfficientNet-B0 and Grad-CAM.
- ⚡ **Philosophy:** Clean code, high data integrity, robust architecture, and seamless user experiences.
